## Platform

web

## Purpose and Users

Self Hosted Runner selects runners for GitHub Actions projects owned by `arklanq`. The homepage helps the owner understand the service and reach its workflow example or repository.

## Constraints

The homepage is deliberately minimal, uses English copy, and reuses the existing application icon. It is a static document alongside the existing API, with no framework, client-side JavaScript, or new dependencies.
